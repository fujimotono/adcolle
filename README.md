# ADcolle Landing Page

## ファイル構成
- index.html
- style.css
- script.js

## VS Codeでの確認方法
1. フォルダをVS Codeで開く
2. 拡張機能「Live Server」をインストール
3. index.htmlを右クリック
4. 「Open with Live Server」を選択

## 修正が必要な箇所
- 電話番号
- 会社情報
- 制作実績
- 料金
- 導入企業数
- お問い合わせフォームの送信先
- 画像

## 注意
画像はUnsplashの外部URLを使用しています。正式公開時は自社画像へ差し替えてください。
