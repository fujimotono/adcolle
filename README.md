# ADcolle Ver.4

Ver.3を基に、営業公開に近づけるための料金・問い合わせ導線・SEO設定を追加しました。

## 追加した内容

- 3つの料金プラン
- 電話・LINE・メール相談への導線
- プライバシーポリシー同意欄
- ProfessionalServiceの構造化データ
- ナビゲーションとフッターへの料金リンク
- スマートフォン用の料金表示調整

## 公開前に必ず変更

- 電話番号
- LINE公式アカウントURL
- メールアドレス
- 料金とサービス内容
- 実績の数値
- 問い合わせフォーム送信先
- 会社所在地・営業時間・代表者情報
