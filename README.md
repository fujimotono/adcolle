## 反映方法

GitHub接続済みの `adcolle-site` に、以下を上書きしてください。

- `index.html`
- `css` フォルダ
- `js` フォルダ
- `README.md`

その後、VS Codeのターミナルで実行します。

```bash
git add .
git commit -m "Upgrade hero and brand design"
git push
```
